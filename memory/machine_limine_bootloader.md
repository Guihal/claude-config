Загрузчик на этой машине — **Limine**, конфиг `/boot/limine.conf`, записи снапшотов —
в `/boot/<machine-id>/`. **GRUB и systemd-boot тут нет**, поэтому «перегенерировать конфиг»
нечем: `grub-mkconfig` и `bootctl update` к делу отношения не имеют.

**Главная грабля: строка `cmdline:` продублирована в каждой загрузочной записи** — по одной на
ядро (`linux-cachyos`, `linux-cachyos-lts`) плюс по одной на каждый снапшот Snapper. Правка
одной строки меняет загрузку одной записи; при откате на снапшот параметр молча пропадёт.
Менять параметр ядра — значит править файл целиком по всем вхождениям, сделав перед этим копию
рядом (`*.bak-<timestamp>`), и потом сверять число вхождений:

```bash
sudo grep -c '^ *cmdline:' /boot/limine.conf   # сколько записей всего
sudo grep -c 'ваш_параметр' /boot/limine.conf  # в скольких он появился — числа должны совпасть
```

Действующие параметры текущей загрузки читаются из `/proc/cmdline`, а не из конфига: конфиг
показывает, что будет после ребута. Расхождение этих двух списков — нормальный признак «правка
внесена, ребута не было», а не ошибка.

Файл `/boot/limine.conf` читается только root. Правка загрузчика — необратимое действие
(неверная строка = машина не грузится), поэтому идёт с явным подтверждением и с бэкапом.

Персона юзера собирается только из: его собственных реплик, его правок («нет, я имел в виду»), конфигов, которые он писал руками (`~/.claude/CLAUDE.md`, `~/.claude/AGENTS.md`), git config.

**Запрещено выводить персону из содержимого задач** — `instructions.md`, `context.md`, `audits/**`, `docs/tasks/**`, код проектов. Промпт «проаудируй X по этим правилам» описывает задачу, не человека.

**Why:** tdai `persona.md` (сгенерён 2026-07-27) описывал юзера как китаеязычного специалиста по AI-безопасности/алайнмент-аудиту, строящего закрытый JSON-вердикт-фреймворк с запретом тулов. Генератор прочёл `~/.pi/agent/audits/*/instructions.md` и принял ограничения задачи за черты личности. Каждый факт лежал в файлах, вывод был мусором — и ехал в контекст каждой сессии как «кто юзер».

**How to apply:** на каждое утверждение о юзере — «он это про себя сказал, или я вычитал из того, что он попросил сделать?» Второе выбросить. Неуверен — не писать. Персона межинструментальная (CC / pi / codex), поэтому дублирование фактов из `CLAUDE.md` в ней оправдано — другие инструменты его не читают. См. [[verify-intent-not-execution]].

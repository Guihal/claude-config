Юзер (2026-08-23): «задачи в память никогда не закидываются». Повод — я завёл в
`~/.claude/memory/` файл, описывающий отложенную задачу («правка контракта критика после 030305»).
Это промах адресом.

**Почему:** память — durable факты, фидбек, преференции, reference. Задача — это работа с
состоянием (не начата / в работе / сделана), у неё другой жизненный цикл и другое место.

**Как применять:** отложенную работу класть durable-файлом в `~/plans/` (готовый к превращению в
кристалл) и/или в трекер задач сессии — НЕ в `~/.claude/memory/`. В память идёт только сам вывод
о том, КАКИМ быть всегда (правило/фидбек), а не «сделать X потом».

Когда юзер просит навязать агенту стиль мышления через `~/.claude/mcp/injection-rules`, лозунг
уровня «думай системно / be holistic» инжектить нельзя: модель (в т.ч. Opus) превращает такую
формулировку в ритуальную болтовню, а при перегрузе начинает дрочить уже сами мета-правила.

**Why:** абстрактную установку модель не исполняет — исполняет конкретную операцию. Ценность даёт
процедура смены уровня абстракции и STOP-условия, а не декларация.

**How to apply:**

- Кодируй **процедуру**, а не установку: `цель → инварианты → границы → состояния/переходы →
  реализация`, а не «мысли шире».
- Держи 4-6 жёстких эвристик, не 50 пунктов чеклиста.
- Самые острые приёмы: **semantic stop** (уточнять семантику слова только когда разночтение меняет
  поведение/гарантии/границы/архитектуру — режет дрочево формулировок) и **counterfactual rename
  test** (рассуждение рассыпалось после переименования сущностей → оно на словах, а не на системе).
- Дели по blast radius: главный агент универсален, получает почти весь каталог → острые эвристики
  в инжект-правила (`00` always-on для глобального принципа, `20` для инвариантов); процедуру
  **по ролям** клади в роль-промпты `~/.claude/agents/*.md` — они не едят инжект-бюджет
  (`planner` L0→L2 до файлов; `worker` инварианты апстрима как authoritative; `critic` линзы
  local-patch-vs-systemic / special-case-vs-general / impl-promoted-to-requirement).
- Семантика уместна на уровне worker (спека authoritative), системность — на архитектурном
  (planner/critic).

Бюджет inject не тиски: `CHAR_BUDGET_DEFAULT` в `core.mjs` — пол+рекомендация
(`max(ceil100(пик+резерв), 5500)`), каталог спроектирован расти под контент. Добавил контент →
`node ~/.claude/mcp/injection-rules/tools/budget-sim.mjs --horizon 2000` → подними потолок до
рекомендации; тесно по пику — `--assign` перераспределяет каденции. См. [[abstract_level_first]].

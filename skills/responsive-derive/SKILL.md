# responsive-derive — desktop → мобайл без дизайнера

Макет на один брейкпоинт → `responsive: UNSPECIFIED`. Этот скилл выводит
мобильную вёрстку **только из механически-легитимных трансформаций** и
показывает результат юзеру до пакетов. Что нельзя вывести — не выдумывать.

## Кто владелец `## Responsive`

**Первый проход — владеет `design-tz-draft`**: если UNSPECIFIED всплыл при
сборке ТЗ, решается внутри tz-draft-фазы. responsive-derive вызывается **только
когда мобайл-запрос возник ПОСЛЕ готового tz-draft** (v1 был desktop-only,
позже понадобился адаптив). Один владелец секции — не дублировать деривацию в
двух местах.

## Легитимно выводить (каталог)

| desktop-паттерн | мобильный вывод |
|---|---|
| multi-col grid | стек в 1 колонку, порядок = DOM/смысловой |
| горизонтальный nav | burger + off-canvas |
| типографика (фикс. размеры) | fluid `clamp()` между desktop-значением и выведенным мобильным |
| слайдер N-up | свайп + peek следующего слайда |
| широкая таблица | horizontal scroll внутри контейнера |
| hover-состояния | active/tap-эквивалент |
| touch-таргеты | ≥44×44px hit-area |
| section-gap | пропорционально ужать (не обнулять ритм) |
| картинки | сохранить aspect-ratio (не кроп) |

`clamp()` — с **явными viewport-границами** (напр. 375–1440px), не «магический»
clamp: `clamp(<mob>, <fluid vw>, <desktop>)`.

## Нельзя без дизайнера (запретный список)

- **art-direction hero** — другой кроп/другая картинка под мобайл.
- **скрытие контента** — `display:none` смыслового блока.
- **изменение смыслового порядка** секций.
- **радикальная смена компонента** (табы → аккордеон) — можно **предложить**
  как вариант, не решать самому.

Наткнулся на такой случай → отметить в выводе как `## Needs designer` и не
реализовывать.

## Выход + human-гейт

Секция `## Responsive [derived]` для `tz.<page>.md` (или патч tz-draft):

```markdown
## Responsive [derived]
breakpoint-source: desktop 1440 only → derived mobile ≤768

- layout.bestsellers.grid: 4-col → 1-col стек (порядок из DOM)
- nav.primary: горизонт → burger + off-canvas
- type.hero.title: clamp(32px, 6vw, 56px)  // bounds 375–1440
- bestsellers.slider: 4-up → свайп + peek 0.15 след. слайда
- targets: все .btn/.link min 44×44px

## Needs designer
- hero.media: возможна art-direction (мобильный кроп) — решает дизайнер
```

⛔ **Human-гейт:** derived-план показывается юзеру ДО генерации пакетов. Вывод
— гипотеза, не факт из макета; юзер подтверждает или правит. Не гнать в tasks
молча.

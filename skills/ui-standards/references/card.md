# Card

## Anatomy
Контейнер → media (картинка/видео) + body (kicker? + title + text? + meta?) +
[actions/link]. Карточка в гриде/слайдере — размер диктует родитель.

## Layout laws
- `display: flex; flex-direction: column`; прижатие низа (meta/actions) —
  `margin-top: auto`, не фиксированная высота карточки.
- Media: `aspect-ratio` + `object-fit: cover`; без height в px.
- Равная высота карточек в ряду — даёт грид (`align-items: stretch`), не
  min-height подгонкой.
- Внутренний padding — токен; сетка карточек — `gap` родителя, не margin.

## Variants & sizing
- Акцентная/большая карточка — модификатор (span грид-колонок + крупнее
  типографика), та же DOM-структура.
- Горизонтальная карточка — `flex-direction: row` модификатором.

## States
Кликабельная карточка: `hover` (тень/сдвиг/зум media — что-то одно),
`focus-within` (ring, когда фокус на внутренней ссылке).

## A11y
- Кликабельность: ОДНА настоящая ссылка (обычно на title), зона клика
  расширяется псевдоэлементом (`::after; inset: 0`). Не `<a>` вокруг всей
  карточки с вложенными интерактивами и не onclick на div.
- Title карточки — заголовок правильного уровня; картинка — осмысленный alt
  или пустой при декоративности.

## Antipatterns
- `height: 420px` на карточке — контент другой длины ломает всё.
- Вложенные ссылки (карточка-ссылка + кнопка внутри) без stretched-link
  паттерна.
- Обрезка текста без `line-clamp` (или clamp без title/полной версии где
  текст значим).

## Repo hint
Карточки почти всегда уже есть (article-card, product-card...) — новый тип =
модификатор существующей, сверить BEM/нейминг проекта.

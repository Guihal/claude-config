# design-diff — v2 макета → точечный патч

Цель — **избежать полного перепрогона**. Существующая карта = база; проходим
новый макет поверх неё и патчим только изменившееся.

## Границы применимости

design-diff — **только post-tz**: когда пришла v2 макета ПОСЛЕ того, как
`tz.<page>.md` уже готов. Если вход изменился в процессе фаз 1–5 (ТЗ ещё не
собран) — действует правило пайплайна: перезапустить незавершённую фазу, слаги
сохранять. design-diff их не подменяет.

## Граф владения артефактов (контракт)

Патчи идут по графу сверху вниз, каждый слой владеет своим:

```
block-map (структура, слаги) → style-map (значения) → tz (UI-решения) → tasks (пакеты)
```

Изменение классифицируется на верхнем затронутом слое и протягивается вниз
только по нужным слагам.

## Вход

- Новые скрины (обязательны) + новая код-выгрузка (если есть — иначе значения
  изменившихся блоков = MISSING, как в фазе 2).
- Существующие `block-map.<page>.md` (+ `shared.block-map.md`) и
  `style-map.<page>.md`.

## Процесс

Пройти новый макет с существующей картой как базой; каждый слаг классифицировать:

- **unchanged** — блок и значения совпали → **не трогать** (суть скилла).
- **changed-values** — структура та же, значения другие → патч только style-map
  (и tz-секция значений).
- **changed-structure** — изменилась вложенность/состав блока → патч block-map
  + вниз по графу.
- **removed** — блок исчез → пометить removed во всех артефактах (слаг не
  переиспользовать под другое).
- **added** — новый блок → **минт нового слага по правилам `design-block-map`**
  (не переименовывать соседние).

**Слаги существующих блоков НЕ переименовывать** — иначе теряется связь с tasks
и conformance.

Опционально: **screenshot-diff** старой и новой версии как доп.сигнал против
ложного unchanged (глазом легко пропустить сдвиг в 4px) — если тулзы сессии
позволяют.

## Выход, формат + пример

`<design-dir>/diff.<page>.<yyyy-mm-dd>.md`:

```markdown
# diff: factory · 2026-07-22

## changed-values
- hero.title — font-size 48→56px
- hero.kicker — color #626262→#1F1F1F

## changed-structure
- bestsellers.slider — добавлен уровень bestsellers.slider.card.badge внутри карточки

## added
- promo.banner (новый слаг, между hero и bestsellers)

## removed
- footer.newsletter

## unchanged
- contacts.* — без изменений (не трогать)

## Патч-инструкции (по графу)
- block-map: +promo.banner, +bestsellers.slider.card.badge, −footer.newsletter
- style-map: hero.title/hero.kicker значения; значения promo.banner (новая выгрузка)
- tz: секции hero, promo, bestsellers
- tasks: перегенерить T(hero), T(bestsellers); +T(promo); убрать footer.newsletter из T(footer)
```

## Далее

Патч-инструкции ведут точечный перезапуск фаз (только затронутые слаги) →
изменённые tasks → пакеты через `tz`. unchanged-таски не перегенерировать.

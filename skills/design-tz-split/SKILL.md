# design-tz-split — ТЗ → цепочка тасков

Фаза 5 цепочки (после `design-project-bind`). Вход — `tz.<page>.md` (контракт —
скилл `design-project-bind`).

## Нарезка

1. **task 0 — foundation**: NEW tokens, базовые стили/переменные, общие
   компоненты, нужные ≥2 секциям. Всегда первый.
2. **task data-layer** (только если в ТЗ есть `NEW sources`): регистрация
   полей/схемы по дескрипторам. **risk-tier: schema** — план/ревью перед
   выполнением, не бандлить с вёрсткой.
3. **task N — по секции страницы** (мелкие смежные секции можно связкой).
   Внутри: структура → стили → поведение → data-binding секции.
4. **task final — интеграция**: сквозной смоук страницы, responsive-политика
   из ТЗ, `## Conflicts` должны быть решены (нерешённый conflict = блокер
   финала, не молчаливый выбор).

Зависимости: `0 → (data-layer ‖ секции) → final`. Секции друг от друга
независимы — помечать как параллелизуемые.

## Каждый task

- Цель одной строкой + слаги секции.
- Файлы-ориентиры (из Repo profile ТЗ).
- Зависимости (номера тасков).
- **Acceptance — только проверяемое**: URL отдаёт 200; селектор/блок present;
  ключевые стили применены (computed style / grep класса); states работают
  (hover/focus проверяемы в браузере); данные тянутся из указанного источника,
  не хардкод (grep шаблона). Непроверяемое («выглядит хорошо») — не acceptance.

## Выход, формат + пример

`<design-dir>/tasks.<page>.md` — один файл, таски по порядку:

```markdown
# tasks: factory

## T0 — foundation [deps: —]
Токен `--accent-gold: #B08D57`; конфиг слайдер-утилиты для hero.media.
Acceptance: токен в карте токенов (grep); build зелёный.

## T1 — data-layer [deps: —] [risk: schema]
Поле factory_kicker {text, editable} по дескриптору из tz.md §NEW sources.
Acceptance: поле видно в админке/схеме; существующие данные не тронуты.

## T2 — hero [deps: T0, T1] [parallel: T3]
Секция hero по tz.md §hero (слаги hero.*).
Acceptance: URL 200; .hero present; breadcrumb aria-current; слайдер листает,
dots активны; lead из поля factory_description (в шаблоне нет хардкода — grep).

## TF — интеграция [deps: all]
Смоук всей страницы; responsive-политика соблюдена; Conflicts из tz.md решены.
```

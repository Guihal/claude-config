# Аудит правил — находки (2026-08-10)

Статус: research-часть закрыта, prune-часть (агент по 31 правилу) — в работе.

## Решение юзера (settled, не переоткрывать)

**Напоминалки помогают даже сильной модели. Их не удаляем — только режем.**

Это разрешает конфликт, который дал research: гайды по context engineering для
Claude-5 требуют выкидывать «emphasis scaffolding» (ALL-CAPS, ⚠️, «CRITICAL»,
повторы) как не влияющее на следование. Наблюдение юзера — обратное, и оно
старше: правило, сказанное один раз мягко, игнорируется.

Практический вывод: **резать объём, не резать сам факт напоминания.** Тройной
повтор одного правила → один блок (сделано в CLAUDE.md 2026-08-10, 188 → 97
строк, содержание всех трёх копий сохранено). Императивная форма (`DO:`,
глагол первым) остаётся везде.

### 1. Калибровка порога «спросить vs делать»

Критерий в CLAUDE.md есть («2+ равновероятных интерпретации»), якоря нет.
Источники требуют один worked example, показывающий, где стоит планка.

Готовый пример из сессии 2026-08-09/10:
- «перенеси тулзы из pi» → НЕ спрашивал какие, составил инвентарь сам.
- удаление чужого `.markdownlintrc` в репо юзера → спросил.

### 2. Environment gotchas (факты, которые удивляют)

Сейчас размазаны по сессиям и теряются при компакте:
- shell fish (уже в AGENTS.md);
- node v26 исполняет `.ts` нативно (`process.features.typescript === "strip"`),
  но не переваривает enum / namespace / parameter properties;
- bun — `~/.bun/bin/bun`;
- chromium для playwright — `~/.cache/ms-playwright` (или `CHROME_BIN`);
- searxng-контейнер поднимается лениво, гаснет через 300 c простоя;
- Linux `MAX_ARG_STRLEN` = 128 KiB на один элемент argv → большой payload
  через argv даёт `spawn E2BIG` (реальный баг Stop-хука, 2026-08-09).

### 3. Архитектурные (трёх нет ни в ponytail, ни в дефолте)

- **Правь на шве, а не по вызовам.** Есть воронка, через которую проходят все
  случаи — правь её, а не N мест. Пример: отключение линтеров в lint-inject
  сделано одной `neuterPlan` внутри `resolvePlanFor`, а не тремя ветками.
  (Ponytail говорит «root cause, не симптом» — близко, но про баги; это — про
  место любого изменения.)
- **Глушить ошибки можно только на объявленной границе.** Хук, роняющий
  сессию, хуже отсутствия хука → `main().catch(() => {})` там законен. В
  середине логики то же самое = потеря данных. Правило: назови границу, где
  деградация тихая; за её пределами — падай громко.
- **Всё, что агент запускает повторно, обязано быть идемпотентным** (хуки,
  скрипты, миграции). Баг `ensureAutoConfig`, который удалил бы пользовательский
  `.markdownlintrc` — ровно нарушение идемпотентности: второй прогон разрушал
  состояние после первого.

### 4. Мета-правило гигиены

Что уже ловит тулинг — из прозы убирать. С 2026-08-09 висит PostToolUse
lint-хук ⇒ словесные «не забудь прогнать линтер» стали мёртвым весом:
детерминированный гейт сильнее напоминания. Все источники ставят «rules already
enforced by tooling» первым кандидатом на удаление.
